FT FLOW - NETLIFY EDITION

1. Suba esta pasta para um repositório GitHub.
2. Na Netlify, crie um novo site pelo Git.
3. Configuração:
   Build command: npm install
   Publish directory: frontend
   Functions directory: netlify/functions

4. Variáveis de ambiente na Netlify:
   DATABASE_URL=URL_DO_NETLIFY_DATABASE_POSTGRES
   SMTP_HOST=smtp.gmail.com
   SMTP_PORT=587
   SMTP_USER=seuemail@gmail.com
   SMTP_PASS=senha_de_app_sem_espacos
   ADMIN_ALERT_EMAIL=email1@gmail.com,email2@gmail.com

5. Login inicial:
   admin / 123
   operador / 123
